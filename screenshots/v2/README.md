# Kâmus App Store görsel taslağı v2

Üretim: ParthJadhav/app-store-screenshots becerisinin yerel editörü.
Editör projesi: ../../store/ios/screenshot-studio/
Önizleme: preview.jpg
Dört boyutta dört ekran: export/ios/iphone/

İlk iki görsel Kâmus’ta Ara paylaşım eklentisini öne çıkarır. Paylaşım menüsü ve anlam kartı, iPhone simülatöründe Safari üzerinden gerçek eklenti kullanılarak yakalandı. Safari’deki okuma metni bu demo için yerel olarak yazıldı; gerçek bir yayın veya üçüncü taraf ürün ekranı değildir.

Mağazaya yüklenmedi. iPad sürümü bu tasarım turunda oluşturulmadı; önce iPhone taslak yönü incelenecek.

Editörü yeniden başlatma:
cd ../../store/ios/screenshot-studio
pnpm install
pnpm run dev --port 3017
