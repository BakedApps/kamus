# Kâmus yeni logolu App Store görselleri

28 Ekim 2026. app-store-screenshots editöründeki mevcut dört iPhone tasarımının kaynak ekranları yenilendi. Ana arama ekranı, paylaşım menüsü, paylaşım uzantısındaki anlam kartı ve favoriler, güncel iOS derlemesinden yeniden yakalandı.

- Önizleme: preview.jpg
- PNG paketi: kamus-ios-guncel-logo.zip
- 4 ekran × 4 iPhone boyutu: export/ios/iphone/
- Kaynak yakalamalar: raw/iphone/
- Editör: ../../store/ios/screenshot-studio/
- Önceki editör ayarlarının kopyası: editor-before-refresh.json

6.9 ve 6.5 inç yükleme boyutları asc ile doğrulandı: sıfır hata/uyarı. Dışa aktarmada React güncellemesi tamamlanmadan önceki ekranın yakalanmasına neden olan zamanlama sorunu flushSync ile düzeltildi; çıktıların birbirinden farklı olduğu yeniden doğrulandı.

Mağazaya yüklenmedi. Mevcut tasarım, metinler ve kullanıcı tarafından ayarlanmış büyüteç konumu korundu.
